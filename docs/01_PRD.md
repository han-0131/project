# PRD — 현장별 공정·기성 대시보드

## 한눈에 보기

- 본사 공무팀 담당자가 매달 12개 현장의 공정·기성을 한 화면에서 비교하는 PC 웹 앱입니다.
- 첫 화면은 점검이 필요한 현장 순위이고, 그 위에 전체 기성률·공정률 큰 숫자 한 줄을 둡니다.
- 월·지역·공사 유형·현장으로 범위를 고르고, 같은 범위를 CSV로 내보내며, AI가 점검 이유를 기록된 근거로 설명합니다.
- 교육용 가상 자료(현장 A~L 12곳, 2025-10~2026-09, 144행·15개 열)를 쓰며, 실제 회사 자료가 아닙니다.
- 로그인·데이터베이스·실제 청구는 만들지 않습니다. GitHub 저장과 Vercel 배포는 사용자가 따로 요청한 뒤에 진행합니다.

## 누가·언제·왜 쓰는지

| 항목 | 내용 | 근거 |
|---|---|---|
| 누가 | 본사 공무팀 담당자 (추천 수용) | 매달 현장 자료를 모아 비교·보고하는 일이 이 자료의 구조(월별 × 현장별)와 맞습니다. |
| 언제 | 매달 월말 자료를 받은 뒤, 자료 파일을 한 번 가져와서 씁니다. (AI 결정) | 자료의 한 행이 "한 현장의 한 달 월말 상태"입니다. |
| 왜 | 어느 현장이 계획보다 늦은지, 그 이유가 무엇으로 기록돼 있는지를 한곳에서 확인하려고 씁니다. | 지금은 현장별 엑셀을 하나씩 열어 비교해야 합니다. |

## 줄이고 싶은 불편

| 순위 | 불편 | 근거 |
|---|---|---|
| 가장 먼저 | 현장별 엑셀을 하나씩 비교하는 시간 (추천 수용) | 12개 현장을 월별로 비교하려면 파일을 열고 맞춰 보는 시간이 가장 많이 듭니다. |

이 앱은 12개 현장을 한 화면에서 같은 기준(같은 월·같은 필터)으로 보여 줍니다. 기성률·공정차이·상태는 프로그램이 계산하므로 손계산도 줄어듭니다.

## 사용자가 정한 것 (질문 7개)

| 순서 | 질문 | 정한 답 | 정한 이유 |
|---|---|---|---|
| 1 | 주로 누가 쓰나요? | A. 본사 공무팀 담당자 (추천 수용) | 월별로 모아 비교·보고하는 업무와 맞습니다. |
| 2 | 가장 먼저 줄일 불편은? | A. 현장별 엑셀을 하나씩 비교하는 시간 (추천 수용) | 파일을 하나씩 열어 비교하는 시간이 가장 큽니다. |
| 3 | 첫 화면에서 먼저 보여 줄 것은? | A. 점검이 필요한 현장 순위 (추천 수용), 위에 큰 숫자 한 줄을 함께 | 어느 현장을 먼저 봐야 하는지 첫 화면에서 알 수 있습니다. |
| 4 | 점검 현장 한 줄에 함께 보여 줄 숫자는? | C. 계획·실제 공정률과 기성률 모두 (추천 수용) | 공정차이가 어떤 숫자에서 나왔는지 한 줄에서 확인할 수 있습니다. 공정률(공사 진도 기준)과 기성률(계약금액 대비 인정된 금액 기준)은 기준이 다릅니다. |
| 5 | 점검 현장 한 줄을 누르면? | A. 현장별 비교표로 가서 그 현장 줄을 강조하고 기록을 펼침 (추천 수용) | 순위에서 기록된 상황·대응 계획까지 한 번에 이어집니다. |
| 6 | 내려받은 CSV는 어디에 쓰나요? | B. 엑셀에서 더 계산하기 (추천 수용): 원본 15개 열에 기성률·공정차이·상태·당월기성액 4개 열을 추가한 19개 열 | 엑셀에서 다시 계산하지 않고 바로 정렬·합계에 쓸 수 있습니다. |
| 7 | AI에게 주로 무엇을 묻나요? | A. 점검 이유와 기록된 대응 설명 (추천 수용) | 숫자는 프로그램이 보여 주고, AI는 그 숫자 뒤에 기록된 상황과 계획된 대응을 풀어 줍니다. |

## 만들 기능 (필수 기능)

| 번호 | 기능 | 사용자가 할 수 있는 일 | 정한 근거 |
|---|---|---|---|
| 1 | 자료 가져오기 | CSV 또는 JSON 파일을 고르면 검사 결과와 미리보기를 보고, 확인하면 전체를 교체합니다. 오류가 있거나 취소하면 지금 자료를 그대로 둡니다. CSV 뒤에 같은 JSON을 가져와도 144행입니다. | 잘못된 파일이 정상 자료를 망가뜨리지 않게 하기 위해서입니다. |
| 2 | 현황 보기 | 처음에는 2026년 9월·전체 현장이 보입니다. 월·지역·공사 유형·현장을 고르면 전체 기성률, 계획·실제 공정률, 공정차이와 선택 월까지의 추이, 월별 기성 막대가 같은 범위로 바뀝니다. 금액은 백만원, 비율은 소수 첫째 자리까지 표시합니다. 전월 자료가 없는 첫 달의 당월기성액과 자료가 없는 범위는 0이 아니라 "계산 불가"로 보여 줍니다. | 한 화면에서 비교하려는 불편(질문 2)을 해결합니다. |
| 3 | 점검 현장 찾기 | 공정차이(실제 − 계획, pp)로 점검(-5pp 이하)·주의(-5pp 초과 0pp 미만)·정상(0pp 이상)을 구분하고, 공정차이가 작은 순(같으면 현장 ID 순)으로 점검 현장을 보여 줍니다. 한 줄에는 계획·실제 공정률, 공정차이, 기성률이 함께 나오고, 누르면 비교표로 이동해 그 현장 줄이 강조되며 기록이 펼쳐집니다. 비교표에는 지역·유형·당월 주요 공종이 함께 나오고, 펼침 행에는 공사기간·기록된 상황·대응 계획이 나옵니다. | 질문 3·4·5의 답을 그대로 반영했습니다. |
| 4 | CSV 내보내기 | 지금 고른 월·지역·유형·현장과 같은 범위를 내려받습니다. 원본 15개 열에 기성률·공정차이·상태·당월기성액 4개 열이 추가되고, 숫자와 단위를 그대로 유지하며, 엑셀에서 한글이 깨지지 않습니다. | 질문 6의 답(엑셀에서 더 계산하기)을 반영했습니다. |
| 5 | AI에게 묻기 | 지금 범위를 확인하고 예시 질문을 고르거나 직접 질문을 입력합니다. 답변에는 기준 월·현장·근거 숫자·참고한 기록 필드가 함께 표시됩니다. 계산은 프로그램이 하고 AI는 그 숫자를 근거로 설명합니다. 기록된 상황은 "기록된 상황", 대응 계획은 "계획된 대응"으로 설명하며, 원인 확정이나 완료 사실로 바꾸지 않습니다. 실제 준공일·미수금처럼 자료에 없는 내용은 "자료 없음"으로 안내합니다. 범위를 바꾸면 이전 답변을 지우고, AI 연결이 실패해도 대시보드와 CSV는 계속 쓸 수 있습니다. | 질문 7의 답을 반영했습니다. AI가 숫자를 만들어 내지 않도록 계산과 설명의 역할을 나눕니다. |

## 만들지 않는 것

| 만들지 않는 것 | 이유 |
|---|---|
| 로그인 | 이번 실습은 사용자 구분이 필요 없습니다. |
| 데이터베이스 | 파일은 브라우저에서 읽고 계산합니다. 서버에 저장하지 않습니다. |
| 회사 시스템 연동 | 자료는 교육용 가상 자료입니다. |
| 실제 기성 청구·발주 | 이 앱은 현황을 보는 용도입니다. 자료에 청구액·수금액·미수금 정보도 없습니다. |
| 일정 예측 | 계약상 준공일은 예정 일정이며 실제 완료일·예측일이 아닙니다. |
| 새로고침 후 자료 유지 | 새로고침하면 파일을 다시 가져옵니다. |
| 별도 상세 페이지 | 현장 기록은 비교표 안에서 펼쳐 봅니다. |
| GitHub 저장·Vercel 배포의 자동 실행 | 사용자가 따로 요청한 뒤에 진행합니다. |

## 화면 요약

- 페이지 4개: 현황 요약(첫 화면) / 현장별 비교표 / 자료 가져오기 / AI에게 묻기
- 상태 5개: 자료 없음 / 가져오기 오류 / 점검 대상 없음("선택한 범위에 점검이 필요한 현장이 없습니다", AI 결정) / AI 답변 기다리는 중 / AI 연결 실패
- 첫 화면 순서: 월·지역·유형·현장 선택 → 큰 숫자 한 줄(기성률·계획/실제 공정률·공정차이) → 점검 현장 순위 → 선택 월까지 계획·실제 추이와 월별 기성 막대
- 점검 한 줄: "D 김포 공동주택 · 계획 86.5% · 실제 75.8% · -10.7pp · 기성률 69.4%". 누르면 비교표의 D 줄이 강조되고 기록이 펼쳐집니다.
- 비교표: 12개 현장의 지역·유형·당월 주요 공종·금액·공정·상태, 펼침 행에 공사기간·기록된 상황·대응 계획
- 숫자 단위: 금액은 백만원, 비율은 %, 공정차이는 pp이며 소수 첫째 자리까지 표시, 자료가 없으면 "계산 불가"
- 상태 구분: 정상(0pp 이상) · 주의(-5pp 초과 0pp 미만) · 점검(-5pp 이하)을 색과 글자로 함께 구분
- 예시 숫자(2026-09 전체): 기성률 67.2% · 계획 73.2% · 실제 71.2% · 공정차이 -2.0pp · 당월기성액 28,878.7 · 점검 D·I·K
- AI에게 묻기: 지금 범위 표시 / 예시 질문("D가 늦어진 원인과 대응은?", "점검 현장은 어디인가요?", "실제 준공일·미수금은?", AI 결정) / 답변에 기준 월·현장·근거 숫자·기록 필드 표시
- CSV: 지금 범위와 같은 행, 원본 15개 열 + 기성률·공정차이·상태·당월기성액 4개 열
