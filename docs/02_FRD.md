# FRD — 현장별 공정·기성 대시보드

## 한눈에 보기

- 화면에서 무엇을 누르면 무엇이 일어나는지를 기능 25개로 정리했습니다. 가져오기·현황·점검 현장·CSV·AI의 5개 필수 기능이 모두 들어 있습니다.
- 월·지역·유형·현장 필터 한 벌을 모든 화면이 함께 씁니다. 숫자·차트·비교표·CSV·AI가 항상 같은 범위입니다.
- 누적기성액(월말까지 쌓인 금액), 당월기성액(이번 달 누적 − 바로 전월 누적), 수금액(자료에 없음)을 구별합니다. 첫 달 당월기성액은 0이 아니라 "계산 불가"입니다.
- 계산과 상태 판정은 프로그램이 하고, AI는 기록된 상황과 계획된 대응을 설명만 합니다. 오류가 나도 지금 자료와 대시보드는 그대로 유지됩니다.
- 시안과 자료가 어긋나는 곳은 자료와 정답 숫자를 따랐고, 그 목록은 맨 아래 "시안과 다르게 정한 것"에 있습니다.

## 4. 계산 규칙 표

금액은 백만원, 비율은 %, 공정차이는 pp입니다. 중간 반올림 없이 계산하고, 화면·CSV에 보이는 마지막 단계에서만 소수 첫째 자리로 반올림합니다. 숫자는 `data/검산표.md` 값입니다.

| 항목 | 계산 방법 | 예시 (검산표 숫자) |
|---|---|---|
| 현장 기성률 | 누적기성액 ÷ 계약금액 × 100 | 9월 D: 50,384.4 ÷ 72,600 × 100 = 69.4% |
| 현장 공정차이 | 실제공정률 − 계획공정률 (pp) | 9월 D: 75.8 − 86.5 = -10.7pp |
| 상태 판정 | 0pp 이상 정상 / -5pp 초과 0pp 미만 주의 / -5pp 이하 점검. 원본이 소수 첫째 자리이므로 10배한 정수로 비교해 계산 오차를 막습니다. issueCategory로 상태를 정하지 않습니다. | 계획 70 · 실제 70 → 0.0pp 정상 / 65.1 → -4.9pp 주의 / 65 → -5.0pp 점검 |
| 점검 순서 | 점검 현장만, 공정차이 오름차순, 같으면 siteId 오름차순 | 9월: D(-10.7) → I(-7.6) → K(-5.4) |
| 상태 건수 | 범위 안 현장을 상태별로 셉니다. | 9월 전체: 정상 6 · 주의 3 · 점검 3 |
| 전체 기성률 | 선택한 한 월·범위의 누적기성액 합계 ÷ 같은 범위 계약금액 합계 × 100 | 9월: 424,063.4 ÷ 630,700 × 100 = 67.2% |
| 전체 계획·실제 공정률 | 현장 계약금액으로 가중평균: Σ(계약금액 × 공정률) ÷ 계약금액 합계 | 9월: 계획 73.2% · 실제 71.2% |

| 표시 형식 | 금액은 천 단위 쉼표 + 소수 첫째 자리, 비율·pp는 소수 첫째 자리. CSV에는 쉼표 없이 숫자만 넣습니다. | 424,063.4 / 67.2% / -2.0pp (CSV: 424063.4) |

**정한 근거**: 산식과 판정 기준은 `data/데이터설명.md`와 `data/검산표.md`를 그대로 따랐습니다. 두 문서와 다른 방식은 쓰지 않았습니다.

## 6. 시안과 다르게 정한 것 (시안 파일: `_1` 현황, `d` 비교표, `_2` 가져오기, `ai` AI)

시안의 배치와 분위기는 따르되, 아래는 자료·PRD·실습조건과 달라서 FRD에서 바로잡았습니다.
