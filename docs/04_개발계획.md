## 한눈에 보기

- EPIC 3개, Story 13개입니다. (실습조건: EPIC 3개 이하, Story 15개 미만)
- 순서: ① 자료 가져오기·필터·현황·추이 → ② 점검 현장·기록 펼침·CSV → ③ 근거를 보여 주는 AI 질의와 전체 검증.
- EPIC마다 끝나면 자동 검사를 실행하고, 브라우저에서 확인할 행동과 보여야 할 결과를 하나씩 확인합니다.

- GitHub 저장과 Vercel 배포는 Story가 아닙니다. 사용자가 각각 따로 요청한 뒤에만 진행합니다.
