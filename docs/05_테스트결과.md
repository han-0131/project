- 확인하지 못한 것은 아래 "확인하지 못한 것"에 따로 적었습니다.

## 5. 확인하지 못한 것

| 항목 | 상태 |
|---|---|
| 확인 14번: 키를 비운 실제 연결 실패 화면 | 사용자의 직접 확인 여부를 받지 못함(선택 항목). 연결 실패 화면은 모의 응답으로 자동 조작 확인, 키 없음 처리는 자동 검사로 확인 |
| 잘못된 키·사용 한도 초과를 실제로 일으킨 경우 | 오류 종류 분류는 자동 검사로만 확인. 실제 상황은 미확인 |
| 시안 이미지와의 닮은 정도 | 개발 담당(AI)이 스크린샷으로 본 판단. 시안 `code.html`의 세부 스타일은 읽지 않음 |
| UTF-8이 아닌 파일, 5MB를 넘는 파일 | 코드에 처리는 있으나 실제 파일로는 확인하지 않음 (txt 파일 거부만 확인) |
| 월 하나만 있는 파일·월별 누락 파일을 화면에서 가져오는 경우 | 자동 검사로만 확인(경고로 처리), 화면에서는 미확인 |
| Vercel 무료 구간의 서버 실행 시간 제한 | 배포 단계에서 확인 (배포 요청 전) |
| `.env.local`이 GitHub에 실제로 올라가지 않는지 | 폴더가 아직 git 저장소가 아니라 확인 불가. `.gitignore`에는 제외 설정이 있음 |
| GitHub 저장, Vercel 배포 | 요청 전이라 실행하지 않음 |
